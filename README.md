# Задание 3 — Мини-продукт с LLM-аналитикой

## Описание проекта

Пользователь отправляет боту CSV или Excel-файл. После получения файла бот анализирует датасет, считает основные метрики, формирует график и отправляет результат пользователю в Telegram.

Для работы с языковой моделью используется Groq API и модель llama-3.3-70b-versatile.

## Запуск проекта

1. Создать `.env` из `.env.example`:

```
cp .env.example .env
```

2. Заполнить переменные:

```
API_KEY=groq_api_key
BOT_TOKEN=telegram_bot_token
ADMIN_ID=telegram_user_id
```

3. Установить зависимости и запустить:

```bash
pip install -r requirements.txt
python main.py
```

После запуска бот будет ожидать файл от пользователя в Telegram.

## Как работает бот

1. Пользователь отправляет Telegram-боту файл `.csv`, `.xlsx` или `.xls`
2. LLM через Groq API получает задачу анализа датасета
3. LLM формирует итоговый аналитический отчёт
4. Telegram-бот отправляет пользователю текстовый отчёт и график

## Пример входного файла

Пример файла `StudentsPerformance.csv`

```csv
gender,"race/ethnicity","parental level of education","lunch","test preparation course","math score","reading score","writing score"
female,"group B","bachelor's degree","standard","none","72","72","74"
female,"group C","some college","standard","completed","69","90","88"
female,"group B","master's degree","standard","none","90","95","93"
male,"group A","associate's degree","free/reduced","none","47","57","44"
```
В этом примере:
* `gender` - пол студента
* `race/ethnicity` - расовая/этническая группа
* `parental level of education` - уровень образования родителей
* `lunch` - тип питания
* `test preparation course` - прохождение подготовительного курса
* `math score` - балл по математике
* `reading score` - балл по чтению
* `writing score` - балл по письму
